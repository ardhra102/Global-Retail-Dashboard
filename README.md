# Global-Retail-Dashboard
An interactive Power BI dashboard analyzing global retail sales and profit trends from 2011 to 2014, focusing on products, customers, segments, and regional performance.

📂 Dataset
- Records: 50,000+
- Tables: Customer, Location, Product, Sales
- Period: 2011–2014

🛠️ Tools & Technologies
- Microsoft Power BI
- DAX
- Data Modelling
- Data Visualization

📈 Dashboard Pages
- Sales Analysis: Sales by category, segment, product, and country.
- Profit Analysis: Profit by category, product, and segment.
- Customer Analysis: Active buyers, valuable customers, and regional performance.

📊 Key Features
- KPI measures for sales, profit, customers, orders, and products.
- YoY and MoM performance analysis.
- Dynamic Top-N ranking.
- Interactive slicers and page navigation buttons.

💡 Key Insights
- Technology recorded the highest sales among categories.
- Consumer was the leading sales segment.
- Canon ImageCLASS 2200 generated the highest product-level profit.
- Tom Ashbrook was identified as the most valuable customer.
- England recorded the highest profitability among countries.

Gained practical experience in Power BI dashboard development, DAX measures, data modelling, KPI creation, and business insight generation.
